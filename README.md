**#React Admin Dashboard**  
A responsive and modern Admin Dashboard UI built with React and Tailwind CSS. It includes routing, sidebar navigation, charts, and a fully responsive layout suitable for SaaS applications.  

**#Features**  
-Responsive dashboard layout  
-Mobile-friendly sidebar with toggle  
-React Router navigation  
-Interactive charts using Recharts  
-Dynamic user table with status indicators  
-Modern UI with Tailwind CSS styling  
-Active menu state handling  
-Reusable components (Navbar, Sidebar, Layout)  
-Fast and clean UI experience.  
  
**#Tech Stack**  
-React.js  
-Tailwind CSS  
-React Router DOM  
-Recharts.  
    
**#Future Improvements**
